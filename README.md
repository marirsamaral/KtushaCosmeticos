# K'tusha Cosméticos — site

Base em React + Vite com Nav, Hero e Produtos, pronta para virar projeto de
portfólio.

## Rodando local

```bash
npm install
npm run dev
```

## Estrutura

```
src/
  components/
    Navbar.jsx / .css
    Hero.jsx / .css
    Produtos.jsx / .css
    Sobre.jsx / .css
    Footer.jsx / .css
  data/
    products.js   -> lista dos 4 produtos (edite aqui nome/descrição/volume)
  App.jsx
  index.css        -> tokens de cor/tipografia (variáveis CSS em :root)
```
